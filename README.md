Thrift Shop - PHP OOP

Deskripsi

Program sederhana berbasis PHP yang mensimulasikan transaksi penjualan barang pada Thrift Shop menggunakan konsep Object Oriented Programming (OOP).

Fitur

- Menampilkan kode toko menggunakan Constant.
- Mengelola data barang menggunakan Class dan Object.
- Menghitung harga akhir setelah diskon.
- Mencetak struk transaksi.
- Menghitung total barang terjual menggunakan Static Property.
- Menampilkan pesan transaksi menggunakan Destructor.

Teknologi

- PHP
- Object Oriented Programming (OOP)

Contoh Barang

1. Jaket Stone Island – Rp350.000
2. T-Shirt Bape – Rp500.000

Tujuan

Memahami penerapan konsep OOP dalam PHP melalui simulasi transaksi sederhana pada toko thrift.
